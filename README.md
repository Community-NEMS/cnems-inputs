## Development tooling

This repo is being set up incrementally, one piece of tooling at a time, so each part
can be reviewed on its own. See
[the Tooling docs](https://community-nems.github.io/cnems-inputs/tools/) for details
on everything that's here so far and how it works:

- [Python Package Skeleton](https://community-nems.github.io/cnems-inputs/tools/#python-package-skeleton)
- [Environment & Task Management with Pixi](https://community-nems.github.io/cnems-inputs/tools/#environment-task-management-with-pixi)
- [Pytest Testing Framework](https://community-nems.github.io/cnems-inputs/tools/#pytest-testing-framework)
- [Git Pre-commit Hooks](https://community-nems.github.io/cnems-inputs/tools/#git-pre-commit-hooks)
- [Code Formatting & Linting](https://community-nems.github.io/cnems-inputs/tools/#code-formatting-linting)
- [Type Checking](https://community-nems.github.io/cnems-inputs/tools/#type-checking)
- [Code & Documentation Linters](https://community-nems.github.io/cnems-inputs/tools/#code-documentation-linters)
- [Test Coverage](https://community-nems.github.io/cnems-inputs/tools/#test-coverage)
- [Documentation Builds](https://community-nems.github.io/cnems-inputs/tools/#documentation-builds)
- [Documentation Publishing](https://community-nems.github.io/cnems-inputs/tools/#documentation-publishing)
- [Dependabot](https://community-nems.github.io/cnems-inputs/tools/#dependabot)
- [GitHub Actions](https://community-nems.github.io/cnems-inputs/tools/#github-actions)
